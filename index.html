Kết Nối Google Sheet
Đồng bộ dữ liệu lên Google Sheets
URL Google Apps Script
Sau khi triển khai Apps Script với quyền "Tôi" + "Mọi người", dán URL vào đây
⚠ Lưu ý quan trọng khi triển khai
Thực thi bằng tên: chọn "Tôi (email@gmail.com)" — KHÔNG chọn "Người dùng truy cập"
Người có quyền truy cập: chọn "Mọi người" — KHÔNG chọn "Bất cứ ai có Tài khoản Google"
Sau khi sửa code: phải triển khai phiên bản MỚI, không phải cập nhật phiên bản cũ
Lần đầu triển khai: Google yêu cầu Uỷ quyền → nhấn "Cho phép" để tiếp tục
Hướng Dẫn Cài Đặt Google Sheet
Kết nối app với Google Sheets để lưu trữ vĩnh viễn
1
Tạo Google Sheet mới
Vào sheets.google.com → Tạo bảng tính mới → Đặt tên "Quan Ly Kinh Doanh". Không cần tạo sheet tab, Apps Script sẽ tự tạo.
2
Mở Apps Script
Trong Google Sheet: Tiện ích mở rộng → Apps Script → Xoá toàn bộ code cũ → Dán code bên dưới vào
3
Dán code Apps Script
Sao chép toàn bộ code bên dưới và dán vào Apps Script

        

      

      
4
Triển khai đúng cách (QUAN TRỌNG)
Triển khai → Triển khai mới → Web app
• Thực thi bằng tên: "Tôi"
• Người có quyền truy cập: "Mọi người"
→ Nhấn Triển khai → Uỷ quyền → Sao chép URL → Dán vào trang Kết nối
